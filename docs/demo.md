## Recording provenance

The first capture's automation used an ambiguous nested-summary selector after the successful genuine recovery. The next section reopens the exact same authenticated persisted mission and completes the budget/handoff steps with no new model call. The join is visibly labelled; it is not presented as a single continuous browser capture. [The manifest](qa-evidence/demo-manifest.json) records raw source hashes, clip bounds, source commit and serving release. An initial edit accidentally trimmed required budget actions; independent review caught it, the source bounds were corrected and the final sequence rechecked before publication. The earlier failed capture/edit remains in private development evidence rather than being treated as a passed run.

The main demonstration uses real model/provider traffic without API-response fixtures. Two naturally observed polling network changes recovered on the final client. A separate [controlled hosted read-loss test](qa-evidence/hosted-read-recovery.json) deliberately drops one actual completed-result response; it is labelled as a controlled browser fault, not a spontaneous outage. The [fixed breadth evaluation](qa-evidence/hosted-breadth/criteria.md) retains3passes/1timeout and is not replaced by the selected demonstration.

Public playback was verified anonymously with actual decode, play, seek and desktop/mobile checks. Audio signal and transcript were checked; perceived synthetic-voice pronunciation was not certified by an audio-capable human in this run. The [submission record](../submission.md) owns final URLs and the still-uncompleted contest/team gates.
